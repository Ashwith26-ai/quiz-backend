Technical Documentation

Online Quiz Management System

A Full-Stack Java Enterprise Web Application developed for academic submission and evaluation.

Project Abstract

The Online Quiz Management System is a full-stack, secure, multi-role web platform designed to automate the authoring, delivery, and evaluation of objective examinations. Traditional paper-based examination systems suffer from high administrative overhead, manual grading delays, and susceptibility to human error. This application resolves these challenges through a centralized role-based architecture where administrators configure quizzes with configurable time limits, marks, and passing criteria, while students engage in interactive timed assessments with instant server-side score calculation and comprehensive performance breakdowns.

Architectural Design

The application adheres to the standard Layered Architecture (Separation of Concerns):

Presentation Layer
Thymeleaf & Bootstrap 5
Dynamic HTML5 UI, CSS3, JavaScript
Controller Layer
Spring MVC Controllers
HTTP routing, Request validation & mapping
Service Layer
Spring Services
Business logic, Scoring, Security rules
Persistence Layer
Spring Data JPA / MySQL
Hibernate ORM, Relational entities & DDL

Relational Entities

Quiz (quizzes) id None title, description, durationMinutes, totalMarks, passingMarks, active

Option (options) id question_id → questions(id) optionText, isCorrect (Boolean flag)
QuizAttempt (quiz_attempts) id student_id, quiz_id startTime, submissionTime, score, percentage, status
StudentAnswer (student_answers) id attempt_id, question_id, selected_option_id marksAwarded

Security Implementation

  • Authentication: Managed by Spring Security 6 with UserDetailsService and session cookies.
  • Password Hashing: BCrypt algorithm with salted multi-round encryption.
  • Authorization: Strict URL ant-matchers enforcing ROLE_ADMIN on /admin/** and ROLE_STUDENT on /student/**.
  • Cheat Prevention: Question options sent to the student browser exclude the isCorrect attribute. Scores are calculated exclusively on the backend upon submission.
  • Duplicate Prevention: Prevents multiple submissions of the same attempt through atomic state transitions.
